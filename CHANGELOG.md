# Changelog

## 1.3.0 - 2026-09-06

- Added shortcut key (`N`) for toggling notes on keyboard
- Added "available puzzles" view for room members while waiting for the room leader to start a puzzle
- Minor UI and visual fixes

## 1.2.0 - 2026-09-03

- Added more flavorful *"Solved!"* text and more exciting Solve Streak styling
- Added changelog view
- Reworked the app footer, making it a more subtle toolbar, adding hover tooltips, and adding actions
- Updated the puzzle select screen with custom icons and overall better UX
- Updated the Puzzle Solved dialog UI
- Fixed a Nonogram bug where the cross character was not appearing correctly
- Fixed a button transparency issue
- Fixed a case where keypad numbers would be incorrectly greyed-out in Suguru
- Fixed players not receiving adequate feedback when they are involuntarily removed from a room
- Updated `README`
- Improved server-side logging and diagnostics

## 1.1.0 - 2026-09-01

- Added Kakuro and Suguru puzzles
- Added a help text feature that contains "How to Play" guides for each puzzle
- Updated UI styling and layouts for better readability
- Improved the reliability of puzzle generation

## 1.0.0 - 2026-08-28

- **Official release!** 🎉
- Cleaned up code, reformatted docs, shortened comments

## 0.4.0 - 2026-08-19

- Improved UI consistency across all views
- Minor visual updates
- Fixed a lingering hover border issue
- Added a *celebration* when solving a puzzle

## 0.3.0 - 2026-08-07

- Added Crossword
- Updated mobile UI to use a floating keypad for all games, including Crossword
- Fixed multiple issues with Crossword puzzle navigation and input
- Updated cell presence indicators to not conflict with cell contents

## 0.2.0 - 2026-08-03

- UI overhaul with enhanced visibility and streamlined interactions
- Added KenKen and Nonogram

## 0.1.0 - 2026-08-02

- First beta testing release with basic functionality
- Room creation, room joining, socket communication, server infrastructure
- Host controls, UI first pass, light and dark theme
- Sudoku game for playtesting
