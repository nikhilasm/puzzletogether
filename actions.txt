PuzzleTogether Actions

Inital connection

Click Switch to Dark Theme
	HTML/JS handles change of color palette and change of button text

Click How to Play
	HTML shows model popup with instruction

Click Submit Feedback
	HTML links button to an external form?

Click join room button
	JS serves a new HTML page

Click create room button
	JS serves a new HTML page

Player joins room
	Player emits a 'playerJoin' signal
	Server receives 'playerJoin' signal, adds player to socket.io channel identified by room code, returns room info/players via socket emit
	JS receives room info, displays HTML page

Host creates room
	Player emits a 'hostCreateNewGame' signal
	Server recieves signal, generates new code, adds player to socket.io channel, returns room info via socket emit
	JS receives room info, determines color of new player, displays HTML page

Player leaves room / on player disconnect
	Player emits a 'playerLeaveRoom' signal
	Server receives signal, emits signal to other players to update their room data
	JS serves landing page

Host leaves room / on host disconnect
	Host emits a 'hostLeaveRoom' signal
	Server receives signal, selects another player in the same room to become new host
	Server emits signal to that selected player to update their status
	Server emits signal to the room to update displayed player info
	JS serves landing page to player

Host start game
	Host emits a 'hostStartGame' signal, with information on which puzzle was requested
	Server receives signal, generates/fetches a new puzzle, emits signal to the channel with the puzzle info
	Players receive signal, parse game data and display puzzle grid

Player click grid cell

Player enter number in grid cell

Player switch notes/solve mode

Host checks solution

Host returns to puzzle select

Player leaves room during active puzzle

Host leaves room during active puzzle

On puzzle solve
